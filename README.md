# Spring Boot Web Application

A Spring Boot web application built using **Spring MVC** and **Thymeleaf** to demonstrate dynamic web page rendering, form handling, and MVC architecture.

## 🚀 Features

- Spring Boot Framework
- Spring MVC Architecture
- Thymeleaf Template Engine
- Dynamic HTML Pages
- Form Handling
- Product Management
- Static and Dynamic Web Pages
- Maven Project Structure

## 🛠️ Technologies Used

- Java 21
- Spring Boot
- Spring MVC
- Thymeleaf
- Maven
- HTML5
- CSS

## ▶️ Getting Started

### Prerequisites

- Java 21 or later
- Maven
- Eclipse IDE / IntelliJ IDEA

### Installation

1. Clone the repository:

```bash
git clone https://github.com/madihaazamahmed-droid/springboot-thymeleaf-demo.git
```

2. Open the project in your IDE.

3. Build the project using Maven.

4. Run the application:

```
SbWebappApplication.java
```

5. Open your browser and access:

```
http://localhost:8080/
```
